GitHub Actions Control API

Continuum is the control plane for allowlisted remote tasks. It keeps the GitHub credential in the protected server environment and returns task results only for a run that Continuum correlated to that task ID.

Configuration and access

Configure NMC_GITHUB_ACTIONS_REPOSITORY, NMC_GITHUB_ACTIONS_WORKFLOW, NMC_GITHUB_ACTIONS_TRUSTED_REF, NMC_GITHUB_ACTIONS_STATE_ROOT and the restricted NMC_GITHUB_ACTIONS_TOKEN. The token is separate from package-download and workspace checkpoint credentials. The runtime state directory is private and must persist across service restarts.

Callers need the github_actions service access claim. GET routes require observe; dispatch and cancellation require control. General Continuum access does not grant this scope.

Routes

Method and routePurpose
GET /github/actions/workflowInspect the one configured workflow and trusted ref.
POST /github/actions/dispatchSubmit an allowlisted task against a fixed trusted ref.
GET /github/actions/tasks/{task_id}Reconcile the persisted task ID to its unique workflow run and return status.
GET /github/actions/runs/{run_id}?task_id=…Read status for the exact run registered to the task.
POST /github/actions/runs/{run_id}/cancel?task_id=…Request cancellation for that registered run.
GET /github/actions/runs/{run_id}/result?task_id=…Download the task's named result archive, capped at 64 MiB.

Dispatch body

{
  "task_id": "5c827e4e-a38f-4c7e-87c7-f53cd6f9efc9",
  "workspace_id": "workspace-one",
  "source_sha": "<40-character checkpoint commit>",
  "source_tree": "<40-character checkpoint tree>",
  "task_kind": "test"
}

Only check, test and python-test profiles are accepted. Repository, workflow and ref come from protected Continuum configuration; callers cannot select arbitrary workflows, branches or GitHub API paths. The workflow's run name includes the task ID so an uncertain response can be reconciled without dispatching a duplicate.

NMC client

Operators can use the Continuum-backed client without calling GitHub directly:

nmc github-actions workflow
nmc github-actions dispatch --task-id UUID --workspace-id workspace-one --source-sha COMMIT_SHA --source-tree TREE_SHA --task-kind test
nmc github-actions task --task-id UUID
nmc github-actions run --run-id RUN_ID --task-id UUID
nmc github-actions result --run-id RUN_ID --task-id UUID --output ./nmide-result.zip
nmc github-actions cancel --run-id RUN_ID --task-id UUID

The result command writes the bounded ZIP to a new path and refuses to overwrite an existing file. Dispatch and cancellation still require the caller's control claim.

Result handling

Continuum verifies that the run belongs to the persisted task before forwarding status, cancellation or results. It selects only nmide-result-{task_id} from that run and proxies the bounded ZIP response. The task broker validates the archive paths, task ID, source commit/tree, profile, run ID and attempt before importing diagnostics or continuing the agent turn.
